# 🏥 Hospital Management System

A simple and user-friendly Hospital Management System developed using **HTML, CSS, and JavaScript**. This project is designed to provide a basic digital platform for managing hospital-related information through a clean and responsive interface.

## 🌟 Features

- 🏥 Clean and user-friendly dashboard
- 👨‍⚕️ Doctor information section
- 🧑‍🤝‍🧑 Patient management interface
- 📅 Appointment booking interface
- 💊 Medical services information
- 📱 Responsive website design
- 🎨 Simple and professional UI

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality

## 📂 Project Structure

```text
Hospital-Management-System/
│

│

    └── images/
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the website and its features.

## ⚠️ Project Limitations

This is a frontend-only academic project. It does not include a backend server or database. Patient information and appointment data are not stored in a secure persistent database.

## 🎯 Project Objective

The main objective of this project is to demonstrate basic web development skills, frontend design, and JavaScript-based interactivity while creating a simple hospital management interface.

## 👨‍💻 Developer

Developed as an academic project to practice frontend web development.
